# Kasturi Mahantt — Personal Portfolio

A responsive personal portfolio website built with semantic HTML, custom CSS and a small amount of vanilla JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — visual system, layout, responsive breakpoints and accessibility states
- `script.js` — mobile navigation and automatic footer year

## Design decisions
- **Visual direction:** editorial, minimal and professional.
- **Palette:** midnight navy, warm off-white and muted gold.
- **Typography:** Playfair Display for display headings and DM Sans for interface and body text.
- **Layout:** clear section hierarchy, generous whitespace, cards and responsive grids.
- **Responsive behaviour:** desktop navigation becomes a collapsible mobile menu; multi-column layouts stack on narrow screens.
- **Accessibility:** semantic landmarks, skip link, keyboard focus styles, descriptive navigation labels and reduced-motion support.

## Run locally
Open `index.html` in a browser. The Google Fonts stylesheet requires an internet connection; system fallback fonts are provided.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and the **/ (root)** folder, then save. Wait for GitHub Pages to finish publishing; the live URL will appear in that section.
