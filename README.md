# Kasturi Mahantt — Personal Portfolio

A responsive personal portfolio website built with **HTML5 and CSS3 only**. No JavaScript is used.

## Files
- `index.html` — semantic page structure, portfolio content and native HTML mobile menu
- `styles.css` — visual system, layout, responsive breakpoints, hover states and accessibility styling

## Design decisions
- **Visual direction:** contemporary editorial portfolio with a distinctive, energetic layout.
- **Palette:** midnight navy, warm off-white, muted gold and lime accents.
- **Typography:** Manrope for strong display headings, Playfair Display for editorial emphasis and DM Sans for body text.
- **Layout:** clear section hierarchy, timeline-style leadership experience, education cards, project panels and generous spacing.
- **Responsive behaviour:** desktop navigation adapts to a native HTML `<details>` menu on smaller screens; multi-column layouts stack on mobile.
- **Accessibility:** semantic landmarks, skip link, keyboard focus styles, descriptive navigation labels and reduced-motion support.

## Run locally
Open `index.html` in a browser. Google Fonts require an internet connection; system fallback fonts are provided.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and the **/ (root)** folder, then save. Wait for GitHub Pages to finish publishing; the live URL will appear in that section.

## Content note
This portfolio presents education, student leadership and early-stage project exploration. Verify dates, descriptions and contact details before academic submission.
